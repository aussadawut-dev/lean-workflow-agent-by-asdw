# Task

Implement `compare(a, b)` in `semver.py` following the Semantic Versioning 2.0.0 specification
(https://semver.org/spec/v2.0.0.html): precedence rules (section 11) and the version grammar.
Invalid versions raise `ValueError`. Standard library only; keep the signature.
`python3 -m unittest discover -s tests` runs the visible tests.
