The source implements meaningful SSRF defenses and pins connections to the vetted IP. This supports a bounded conclusion, not complete SSRF safety. I inspected source and test definitions only; I sent no traffic and executed no tests.

1. **Ports.** Only integer ports **25, 465, 587, 2525** pass normally. Save-time validation and send-time validation both enforce this. `allowAnyPort: true` bypasses the entire policy check, including its integer restriction. Evidence: `application/packages/server/src/infrastructure/providers/smtp-outbound-policy.ts:3`, `application/packages/server/src/infrastructure/providers/smtp-client.ts:198`; assertions cover allowed/rejected ports and the bypass in `application/packages/server/src/smtp-outbound-policy.test.ts:11`, and save/send enforcement in `application/packages/server/src/smtp-connector.test.ts:491`.

2. **Address classification.** IPv4 always-denied entries are `0/8`, `169.254/16`, `192.0.0/24`, multicast `224/4`, `240/4`, and exact addresses `100.100.100.200`, `168.63.129.16`. Loopback is `127/8`; private includes RFC1918 and `100.64/10`. IPv6 denies unspecified, `fe80::/10`, multicast, `64:ff9b::/96`, `2002::/16`, `2001::/32`, and exact metadata address `fd00:ec2::254`; `::1` is loopback and `fc00::/7` private. Zone identifiers and invalid addresses are denied. Other valid addresses fall through to “public.” `application/packages/server/src/infrastructure/providers/smtp-outbound-policy.ts:34`.

   IPv4-mapped and IPv4-compatible IPv6 forms are decoded and recursively classified as IPv4, preventing embedded private/metadata addresses from automatically becoming public. `::` and `::1` retain their IPv6 handling. Dotted and hexadecimal mapped forms have assertions; compatible forms lack explicit cases in the inspected classifier tests. `application/packages/server/src/infrastructure/providers/smtp-outbound-policy.ts:61`, `application/packages/server/src/smtp-outbound-policy.test.ts:27`.

3. **DNS.** Hostnames use one `lookup(..., {all:true, verbatim:true})`; literals skip lookup. Every returned address must pass the effective policy before the first is selected. Thus mixed public/disallowed replies fail, as do resolver exceptions and empty answers, with `SMTP_TARGET_REFUSED`. `application/packages/server/src/infrastructure/providers/smtp-outbound-policy.ts:117`, `application/packages/server/src/smtp-outbound-policy.test.ts:82`.

4. **Relaxations.** Exactly `SMTP_ALLOW_PRIVATE_HOSTS="true"` permits private addresses; explicit `allowPrivate` overrides it. Loopback requires separate `allowLoopback:true`; always-denied addresses remain denied. These options are callable seams, **not enforced as test-only by `NODE_ENV`**. The inspected HTTP controller supplies no internal options. `application/packages/server/src/infrastructure/providers/smtp-outbound-policy.ts:139`, `application/packages/server/src/smtp-outbound-policy.test.ts:105`, `application/apps/api/src/modules/connectors/connector-settings.controller.ts:227`.

5. **Connection and TLS identity.** TCP and implicit TLS receive `target.address`; STARTTLS wraps the existing socket. Hostnames remain `servername`, with `rejectUnauthorized:true`; IP literals omit SNI and use IP identity handling. An optional CA changes trust roots without disabling verification. `application/packages/server/src/infrastructure/providers/smtp-client.ts:92`, `application/packages/server/src/infrastructure/providers/smtp-client.ts:218`. Tests assert SNI, untrusted/mismatched certificate rejection, IP-SAN success, and one-resolution connection pinning. `application/packages/server/src/smtp-connector.test.ts:673`.

Remaining uncertainty: “public” means outside this finite classification, not proven globally safe routing. Deployment routing/NAT/translation, environment configuration, and runtime TLS behavior remain unverified. Explicit STARTTLS hostname-mismatch and negative IP-SAN coverage are absent from the inspected block. Also, the `application/packages/server/src/smtp-connector.test.ts:915` uses an ephemeral port, so earlier port rejection can mask address rejection.
