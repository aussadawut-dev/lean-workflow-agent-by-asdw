# TCK013 — First actual usage improvements: test selection, target gate cache/logging, guard ergonomics, and agent batching

Status: DONE
Owner: agy

## Goal

Eliminate the workflow bottlenecks and false-positive guard blocks discovered during the first multi-session production run (`casetodian-workspace/chore-tasks-to-done`):
1. Prevent target and queue work-record edits (`.lean/targets/*`, `.agents/queue/*`, `docs/tracking/*`) from triggering full 32-file Lean workflow test runs in `lean test --changed`.
2. Add opt-in tree-state caching for the Target Quality Gate (`--cache-tree`) so workspace tracker/queue bookkeeping does not re-run unchanged target checks, and fix `gate.py`/`target.py` so target gate failures log the actual failure reason and check counts in `activity.jsonl`.
3. Fix Contract Guard (`guard.py`) false positives on `lean ... -h/--help`, `git submodule status/summary`, input redirections (`< $var`), and external user memory/scratchpad paths (`~/.claude/.../memory/`, `/tmp`, `/private/tmp`), and add session-supersede / controller takeover protection against split-brain concurrent controllers.
4. Document subagent thread limits, shared-foundation-first wave sequencing, bounded polling rules, and fallback controller handoff hygiene in `.lean/skills/lean-agents/SKILL.md` and `docs/agents-and-models.md`.
