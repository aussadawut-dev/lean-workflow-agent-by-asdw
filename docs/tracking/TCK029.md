# TCK029 — Four-level actual-token benchmark and 20 percent reduction

Status: BLOCKED
Owner: codex

## Goal

Measure low/medium/high/critical Casetodian investigations against Lean 4.17.0 and 5.8.0, then demonstrate >=20% fewer actual tokens with no quality regression.

## Acceptance criteria

- [x] AC-01: Freeze four distinct source-based tasks, source revision and explicit grading criteria before inference; same model/effort within each task across arms.
- [x] AC-02: Run 4.17.0, 5.8.0 and optimized 5.8.0 with fresh contexts, two repetitions and counterbalanced ordering; retain real usage and failed attempts.
- [x] AC-03: Evaluate quality against frozen facts, including safety/uncertainty requirements, without rewarding shorter but incomplete answers. Report all failures.
- [ ] AC-04: Primary target: >=20% reduction in actual input+output versus 4.17.0, per difficulty and equal-weight aggregate, with no quality loss versus either control; separately report cached/uncached and quota limitations.
- [x] AC-05: Deliver reusable optimization profile, reproducible runner/report, meaningful harness tests, validation, review and shared gate. No unsupported success claim if measured target fails.

## Tasks

- [x] TASK-01: Freeze task bank, rubric and generic focused-context intervention.
- [x] TASK-02: Execute frozen controls and retained intervention trials, one active inference at a time.
- [x] TASK-03: Grade, compare, investigate regressions and document measured outcome.
- [x] TASK-04: Validate, review and gate final artifacts.
